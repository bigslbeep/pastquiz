# 과거형 뜻맞추기 게임

5학년 영어 과거형 동사 학습용 카드 짝맞추기(메모리) 게임입니다.
그룹(①~⑤) 또는 전체 50개 중에서 연습할 범위와 카드 수(짝 개수)를 고르고,
카드를 뒤집어 과거형 영어 단어와 알맞은 한국어 뜻을 짝지으면 됩니다.

- 시간과 시도 횟수가 기록되고, 브라우저에 최고 기록이 저장됩니다.
- 별도 설치나 빌드 없이 `index.html` 파일 하나로 동작합니다.

## GitHub Pages에 올리는 방법

1. GitHub에서 새 저장소(Repository)를 만듭니다. (예: `past-tense-game`)
2. 이 폴더의 `index.html` 파일을 저장소에 업로드(Add file → Upload files)한 뒤 Commit 합니다.
3. 저장소의 **Settings → Pages** 로 들어갑니다.
4. **Branch**를 `main`(또는 `master`), 폴더는 `/(root)`로 선택하고 **Save** 합니다.
5. 1~2분 후 `https://내아이디.github.io/저장소이름/` 주소로 접속하면 게임이 열립니다.

## 단어 목록 수정하기

`index.html` 안의 `GROUPS` 배열에서 `[원형, 과거형, 뜻]` 형식으로 단어를 추가하거나 수정할 수 있습니다.
